## 开始使用

1. 下载与你的电脑对应的 ZIP，完整解压到自己的文件夹。
2. Windows 双击“打开报告库.bat”，Mac 双击“打开报告库.command”。浏览器会打开本地页面，运行期间保留启动窗口。
3. 输入企业名或证券代码，按行业及年度筛选；选择保存文件夹后，可以下载单份、所选、企业、行业筛选结果或全库报告。
4. 只使用单 HTML 时，双击文件即可离线搜索；单份原文通过浏览器查看与保存，批量下载使用系统包。

Mac 可在苹果菜单“关于本机”查看芯片：Apple M1/M2/M3 等选择 M 系列包，Intel 处理器选择 Intel 包。

## 内容与更新

v2.1.0 包含 **8,282 个企业条目、42,235 份报告索引**。公告发布日期范围为 **2021-01-01 至 2026-09-27**，年度筛选提供 2021—2025 报告年度。

系统包包含完整工具、索引、运行组件和使用说明。**PDF 原文按需联网下载，初始包没有预装全库 PDF。** 下载后的 HTML 可离线搜索，已保存的 PDF 可离线阅读。不同语言、摘要和修订版本分别记录。

以后在完整包中双击“更新报告索引”，可更新至执行当日。HTML 是生成时的数据快照，更新后请重新分享新文件。

## 使用提示

- “下载筛选结果”包含所有分页；“下载全库”覆盖整个索引，不受当前筛选限制。
- GitHub 自动提供的 `Source code` 压缩包仅包含本仓库文件。运行工具请选择上方系统完整包。
- GitHub 下载可达性取决于使用者的网络。文件下载后，本地检索不依赖 GitHub，也不需要分享者开机。
- Mac M 系列启动及下载已核验，Intel 运行组件经过 Rosetta 检查；Windows 尚未完成实机验收。
- Python 及随附运行组件的许可文件保留在各系统包的 `runtime` 内。报告正式引用请核对原文。
